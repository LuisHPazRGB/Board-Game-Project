# Board-Game-Project
Jogo da Velha de Terminal

Com esse código é possível jogar um jogo da velha diretamente do terminal do seu computador.
No terminal, você escolhe um nome para um primeiro jogador e um nome para um segundo e partir do uso de um sistema 
de escolha de casas com base em números que vão de 0 a 2 para as linhas e para as colunas é possível jogar o jogo da velha.
As casas vão sendo preenchidas e caso der velha o jogo acaba
